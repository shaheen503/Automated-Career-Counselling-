# Automated Career Counselling

An academic machine-learning project that explores career recommendations using student-related inputs such as academic performance, interests, and skills.

## Project Overview
The application demonstrates how a classification model can be used to support career exploration. Recommendations should be treated as guidance, not as a substitute for professional counselling.

## Technology
- Python
- Machine Learning
- Random Forest (as used in the project)

## Key Areas
- Working with student input features
- Preparing data for model-based predictions
- Presenting career suggestions through an application
